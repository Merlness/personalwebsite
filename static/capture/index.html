Settings

With an API server set, the token is the app token for that server and no GitHub token is needed on this device. Without one, create a fine-grained token at github.com > Settings > Developer settings, scoped to the one organizer repo with Contents read and write. Either way the token is encrypted with your PIN and never leaves this device except to call that one API.

Gemini key (free): aistudio.google.com > Get API key. With it set, clear captures file themselves into the right bucket instantly; ideas and ambiguous notes stay in the inbox for the scheduled triage run.

To install: tap the Install button in the header when it appears, or Chrome menu (⋮) > "Add to Home screen" > Install.
